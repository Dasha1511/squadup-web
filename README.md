# squadup-web — сайт squadup.ru

Лендинг мобильного приложения Squadup. Отдельный проект: бэкенд, мобильное приложение и база данных не затрагиваются.

## Стек
- Astro 7 (статический сайт, 9 страниц + 404, sitemap)
- Шрифт Inter (локально, без Google Fonts), иконки Lucide
- Обработчик формы подписки — `server/subscribe-server.mjs` (Node.js без зависимостей)

Нужен Node.js 22.23.4 или новее (на вашем ПК стоит 24 — подходит).

## Запуск на компьютере (Windows)
```
npm install
npm run dev
```
Сайт откроется на http://localhost:4321. Чтобы работала форма подписки, во втором окне терминала:
```
npm run form-server
```

## Сборка
```
npm run build
```
Готовый сайт — в папке `dist/`.

## Счётчики статистики
Настройки — `src/config/site.ts`, блок `ANALYTICS`. Пока ID пустой, счётчик не загружается.

| Сервис | ЛР | Что вписать |
|---|---|---|
| LiveInternet | №3 | `liveinternet.type` — вид счётчика из кода LiveInternet (фрагмент `hit?t52.6`) |
| Рамблер/топ-100 | №4 | `rambler.projectId` — номер проекта |
| MyTracker / Top.Mail.Ru | №5 | `mytracker.counterId`, `mytracker.logoSrc` |

Все счётчики загружаются только после «Принять» в баннере cookies. Информеры выводятся в подвале.

### События (цели)
| Имя | Когда |
|---|---|
| `notifyclick` | кнопка «Узнать о запуске» / «Скачать» |
| `subscribe` | email успешно отправлен |
| `telegram` | переход в Telegram-канал |
| `storeandroid`, `storeios` | кнопки Android / iPhone |
| `faqopen` | открыт вопрос FAQ |
| `emailclick` | нажат email в контактах |

События уходят в Рамблер/топ-100 (`trackEvent`) и MyTracker (`reachGoal`). Блоки страниц размечены атрибутом `data-sq-block` для «Аналитики блоков» Рамблера.

Проверка в браузере: откройте сайт с `?sqdebug=1` — в консоли видно каждое событие и куда оно ушло. Объект `window.sqAnalytics` хранит список событий страницы.
